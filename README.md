# TP 6 — PHP, MySQL et PDO

Travail pratique de la Licence Développement Web Full Stack et DevOps (2026/2027).

## Contenu

| Fichier | Rôle |
|---------|------|
| `code/01-hello.php` | Premier script PHP : messages, date et heure du serveur |
| `code/02-php-html.php` | Mélange de PHP et de HTML |
| `code/03-get.php` | Paramètres GET |
| `code/04-post.php` | Formulaire POST |
| `code/05-formulaire.php` | Calcul du total (prix × quantité) |
| `code/06-connexion.php` | Connexion à MySQL avec PDO |
| `code/07-select.php` | Affichage des produits + bonus prix > 300 DH |
| `code/database/database.sql` | Base `tp_php` et table `products` |
| `Rapport_TP6.pdf` | Rapport du TP avec les captures d'écran |
| `captures/` | Captures d'écran utilisées dans le rapport |

## Installation

1. Démarrer Apache et MySQL dans XAMPP.
2. Copier le dossier `code/` dans `C:\xampp\htdocs\tp-php`.
3. Importer `database.sql` dans phpMyAdmin (base `tp_php`).
4. Ouvrir http://localhost/tp-php/01-hello.php
